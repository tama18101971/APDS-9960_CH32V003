# AGENTS.md

## Project

APDS-9960 1.5.0 gesture driver for CH32V003, NoneOS-SDK, bare-metal C99.
LEFT/RIGHT/UP/DOWN only. Accepted IDs:0xAB/0x9C/0xA8/0x9E; preserve clone support.


## Editor tooling: clangd + Serena

IntelliSense comes from **clangd** (not from cpptools — it is listed in
`unwantedRecommendations`). Serena's `cpp` backend *is* clangd, so the same
setup powers the Serena symbol tools.

| Artifact | Versioned? | Why |
|----------|-----------|-----|
| `.clangd` | **yes** | Shared driver/target/flag handling. Must stay machine-independent. |
| `.vscode/extensions.json` | **yes** | Extension recommendations. |
| `compile_commands.json` | no | Generated by `pio run -t compiledb`; contains absolute paths of the generating machine. |
| `.cache/` (clangd index) | no | Machine-local, rebuilt automatically. |
| `.vscode/settings.json` | no | Per-machine clangd settings. |
| `%LOCALAPPDATA%\clangd\config.yaml` | no | Per-machine newlib include path, read by every clangd on the machine (including Serena's). |
| `.serena/project.yml`, `.serena/memories/` | **yes** | Shared Serena project config. |
| `.serena/cache/`, `.serena/project.local.yml` | no | Already excluded by `.serena/.gitignore`. |

**Per-machine setup (once per checkout):**

```bash
pio run -t compiledb        # writes compile_commands.json (git-ignored)
```

clangd resolves the NoneOS-SDK headers from that database, but the WCH newlib
headers (`stdio.h`, `sys/*.h`) are injected implicitly by GCC and therefore
absent from it. Add them in the clangd **user** config, never in `.clangd`:
`%LocalAppData%\clangd\config.yaml` (Windows),
`~/Library/Preferences/clangd/config.yaml` (macOS),
`$XDG_CONFIG_HOME/clangd/config.yaml` (Linux).

```yaml
If:
  PathMatch: .*APDS-9960_CH32V003.*
---
CompileFlags:
  Add:
    - -isystem
    - <platformio-packages>/toolchain-riscv/riscv-wch-elf/include
```

Without it clangd cannot build an AST and both IntelliSense and Serena's
symbol tools fail. Regenerate the database after every `platformio.ini`
change; verify with `clangd --check=src/apds9960.c` (exit 0 = clean).

## Platform constraints

- Board ch32v003f4p6_evt_r0,48 MHz, rv32ecxw/ilp32e; NoneOS-SDK, not Arduino/RTOS.
- 2048B SRAM/16384B Flash. No dynamic allocation or float.
- Linker reserves256B stack. readGesture frame96B is measured; complete call-chain/ISR
  watermark is not measured. Do not repeat an unconditional148B peak claim.
- Keep FIFO buffer32B (8UDLR datasets); do not introduce a full128B automatic buffer.

## Implementation and contracts

- library.json version1.5.0; platformio.ini and library dependency pin I2C v7.2.1.
- All tunables/defaults/range guards:src/apds9960_config.h; apply flags project-wide.
- ID0xA8 profile:2x/25 mA base gesture drive. ID0x9E:1x/12.5 mA. Both optional.
  LED_BOOST scales both proximity and gesture. These are empirical board settings,
  not alternate register layouts or a guarantee of every clone's operation.
- GCONF2 GGAIN bits6:5,GLDRIVE4:3. Positive edge delta maps DOWN/RIGHT.
- Gesture metric:average(last2)-average(first2), effective minimum max(4,configured).
  It reduces boundary noise contribution; it is not identical to old telescoping sums.
- FIFO overflow is tested before GVALID. Hardware clear uses GCONF4.GFIFO_CLR.
  I2C faults/deadline return NONE, mark stream for resync before another result.
- Calibration sampling faults/insufficient data can fall back; threshold writes are strict.
  Cache commits only after both writes succeed. recalibrate is not a full reinit.
- GPIO/AFIO clocks and matching INT pin macros are required; EXTI0..7 share one vector.
  Default ISR strong; provide-ISR=0 requires application handler (example includes a fixture).
- Example uses bounded flag/INT-level polling, not WFI or post-gesture discard.
  I2C_ERR_RECOVERY requires successful i2c_init after physical fault correction.
- APIs are single-instance, non-reentrant, not ISR-safe; pointers valid/non-NULL.
- OWN1 owns/normalizes SysTick, stops it on return; deadline checked between I2C calls.
  OWN0 also needs a compatible APDS_DELAY_MS hook to preserve application SysTick.
  SDK Delay_Ms/Us reset/start/stop the upward counter; they are not a shared clock.
- apds9960_log.c/h:integer-only UART output, no stdio/heap. Init UART before DEBUG,
  RAW_DEBUG or I2C_TRACE. Health/HW tests are optional example modes, off by default.
- sleep keeps PON (~38 uA nominal), shutdown clears PON (~1 uA typical per original datasheet).
  Physical sensor power loss requires init, not wakeup alone. Clone currents not measured.
